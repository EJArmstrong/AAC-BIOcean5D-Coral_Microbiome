# BIOcean5D-Coral_Microbiome
Analysis of Acute Heat Shock and Turbidity-Driven Impacts on Coral-Associated Bacterial Communities.

Reciprocal transplantation of *Pocillopora meandrina* (POC) and *Porites rus* (POR) between Opunohu Bay
(turbid, impacted) and Tiahura (pristine), Mo'orea, followed by an acute heat challenge, with 16S
metabarcoding of coral fragments and of free-living seawater (0.2 µm), particle-bound seawater (3 µm)
and benthic sediment references.

## Repository layout

Each numbered analysis step `NN-AAC-Name` keeps its script in `Analysis/NN-AAC-Name/` (knitted to
`.html` + `.md` + `_files/figure-html/`) and writes its outputs to the matching subfolder of `Data/`,
`Figures/` and `Tables/`. Scripts define `dir_out_dat`, `dir_out_fig` and `dir_out_tab` in their setup
chunk and prefix output filenames with `pref_out` (e.g. `05-AAC-CommunityAnalyses_`).

| Step | Script | Consumes | Produces |
|---|---|---|---|
| 01 | `01-AAC-AssignSeqVariants` | `Data/00-AAC-Sequences/` reads | ASV table, taxonomy, ASV fasta, `physeq_raw`, read-tracking; QC figures |
| 02 | `02-AAC-PreProcessing` | `physeq_raw` | `physeq_noControlsChlorosMitos` (controls, chloroplasts, mitochondria removed) |
| 03 | `03-AAC-PhylogeneticTree` | ASVs from the pruned phyloseq | MAFFT alignment, FastTree tree, `physeq_midpointTree` |
| 04 | `04-AAC-DiversityAnalyses` | `physeq_noControlsChlorosMitos` | iNEXT Hill-number object; rarefaction and Hill-profile figures |
| 05 | `05-AAC-CommunityAnalyses` | `physeq_midpointTree` | PERMANOVA / betadisper / post-hocs, environmental tracking, alpha diversity, heat-shock models, DESeq2 differential-abundance tables, turnover, Hill profiles |
| 06 | `06-AAC-ITS2Symbionts` | SymPortal output in `Data/06-AAC-ITS2Symbionts/` | Symbiodiniaceae clade and type-profile composition, PERMANOVA and betadisper on post-MED sequence communities (clade-C UniFrac and Bray-Curtis), heat-shock dispersion result; three figures |
| 07 | `07-AAC-RNAseq` | salmon `quant.sf` files in `Data/07-AAC-RNAseq/` (produced by `Code/07-AAC-RNAseq_quantification.sh`) | *Pocillopora* heat-shock differential expression (DESeq2), mapping-rate/symbiont-fraction QC, expression-space dispersion test; **drafted, not yet run** |

### Large files

Sequence data, reference genomes and aligner indices stay **out** of this repository;
`.gitignore` blocks FASTQ, BAM/SAM/CRAM, `.fna`, GFF/GTF and salmon indices. The RNAseq
read set is 41 GB and the PMEA_v1 reference 347 Mb, both held outside the repo. If a large
derived file ever must be versioned, track it with `git lfs` rather than committing it.

Note that `Data/00-AAC-Sequences/CleanBactSeqs/` and
`Data/01-AAC-AssignSeqVariants/DADAFilteredSeqs/` already carry **479 tracked `.fastq.gz`
files, about 1 GB**, committed before these rules existed. The ignore rules do not untrack
them - gitignore only affects files git is not already following.

Step 06 analyses the **ITS2 Symbiodiniaceae** amplicons and is independent of steps 01-05: the reads
were processed externally with [SymPortal](https://symportal.org/), so no DADA2 stage is involved. Its
inputs (type-profile workbook, post-MED sequence abundances, clade-C distance matrices) were copied out
of the separate `BIOcean5D` working folder, submission `20250128T160811_armster1`; that folder is never
written to from this repository. Statistics are run on the post-MED **sequence** layer because each
sample carries essentially one ITS2 type profile, which makes the profile table near-categorical.

`Code/` holds supporting shell scripts. `Manuscript/` holds all text and summary files — cross-step
summaries, methods and results drafts, and documents written for meetings and deliverables. These are
not pipeline outputs and are not regenerated by any script. Current contents:

* `AAC-MethodsResults_Walkthrough.md` — methods and results for steps 01–05, written against the design
  as actually sampled, with a per-analysis verdict and a re-analysis specification.
* `AAC-ResultsSummary_v2_2026-10-26.md` / `.pdf` — two-page meeting summary.
* `AAC-ResultsSummary_SUPERSEDED_2026-10-26.*` — the first version, retained for reference only. It
  reads `Site` as the fragment's current bay; `Site` is the bay of origin, which inverts its
  environmental-tracking result. Do not circulate.

## Housekeeping notes

* `maaslin2_output_directory/` at the repository root is leftover output from a September 2026 version
  of script 05. The current script writes MaAsLin2 output to its own temporary directory and removes it
  on completion, so nothing regenerates this folder.
* `Results/{Figures,RFiles,Tables}/` holds pre-convention `04-DiversityAnalyses_*` outputs that
  duplicate the role of `Data/04-AAC-DiversityAnalyses/`, `Figures/` and `Tables/`.
* `Analysis/04-AAC-DiversityAnalyses/04-DiversityAnalyses.Rmd` (January 2026) is an older duplicate of
  `04-AAC-DiversityAnalyses.Rmd`.
* `Data/02-AssignASVs/` collides numerically with `Data/02-AAC-PreProcessing/`; step 02 means two
  different things depending on the folder.
* Git LFS tracks `*.gz`, `*.rds` and `*RData` (see `.gitattributes`).
